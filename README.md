# 🌸 Fragrance Wheel Matcher (Система підбору ароматів Brocard)

Інтерактивний програмний комплекс для рекомендації та підбору парфумерії на базі математичної моделі **Колеса Ароматів Майкла Едвардса (14 підгруп у 4 сімействах)**, локальної бази даних SQLite (з готовим продакшн-сценарієм для PostgreSQL), Data Quality Gate валідації та браузерного парсера каталогу Brocard.ua.

---

## 🚀 Швидкий старт (Запуск однією командою)

Для запуску не потрібно налаштовувати сервер баз даних — додаток автоматично створює локальну БД `fragrances.db`, наповнює довідники Колеса, імпортує каталог бестселерів Brocard та підіймає веб-інтерфейс:

```bash
cd "fragrance_matcher"
python3 run.py
```

Після запуску відкрийте у браузері: **[http://localhost:8000](http://localhost:8000)**

## 🎯 Як працює алгоритм підбору

Колесо Майкла Едвардса розбите на 14 підгруп, розташованих на дискретному кільці з циклічною відстанню:
$$\text{CircularDistance}(i, j) = \min(|i - j|, 14 - |i - j|)$$

Система формує три взаємодоповнюючі кошики рекомендацій:

1. **🎯 Точний збіг (Exact Match, $d = 0$ або те саме сімейство):**
   * Аромати з ідентичною ольфакторною підгрупою (наприклад, для Carolina Herrera Good Girl прямими аналогами є Lancôme La Vie Est Belle та YSL Black Opium).
   * Враховує перекриття серцевих і базових нот піраміди.

2. **🌿 Гармонійні альтернативи (Adjacent Alternatives, $d \in \{1, 2, 3\}$):**
   * Безпечна зона відкриттів: суміжні підгрупи на колесі. Знайомий характер із цікавим новим нюансом (наприклад, перехід від орієнтальної солодкості до пряно-деревного акорду Bad Boy чи Fahrenheit).

3. **⚡ Сміливий контраст (Complementary Contrasts, $d \in \{5, 6, 7\}$):**
   * Діаметрально протилежний бік колеса: несподіване, свіже рішення для зміни образу (наприклад, для важкого східного аромату — іскристий свіжий Dior Sauvage або Giorgio Armani Acqua Di Giò).

## 🗄️ База даних

* **Локальний режим (За замовчуванням):** SQLite (`fragrances.db`) — зберігає структуру Колеса, бренди, піраміди парфумів (ноти зберігаються в JSON-форматі) та кеш рекомендацій.
* **Продакшн режим (PostgreSQL):** Створено готовий DDL-скрипт [`db/01_postgres_schema.sql`](file:///Users/yukhymshulha/Library/Mobile%20Documents/iCloud~md~obsidian/Documents/Slamnom%20notes/fragrance_matcher/db/01_postgres_schema.sql) з ідемпотентними індексами та запитами `ON CONFLICT DO UPDATE`. Для підключення до PostgreSQL достатньо вказати змінну середовища:
  ```bash
  export DATABASE_URL="postgresql://user:pass@localhost:5432/fragrances"
  ```

## 🛡️ Контроль якості даних (Data Quality Gate)

У модулі `pipeline/ingest.py` впроваджено строгу валідацію через Pydantic:
* Кожен парфум обов'язково повинен містити нотну піраміду або категорійну підказку.
* **Жорстке блокування:** якщо ольфакторні ноти не мапляться на жодну з 14 підгруп Колеса Едвардса, запис автоматично відхиляється і не потрапляє в базу.

---

## 🕷️ Збір даних з Brocard.ua

Сайт `brocard.ua` захищений **Cloudflare Turnstile**, що блокує стандартні HTTP-запити. Для збору даних реалізовано:
1. **`scrapers/brocard_scraper.py`:**
   * Підтримка **Playwright** для емуляції реального браузера та проходження челенджу Turnstile.
   * Парсер українських описів піраміди («Початкова нота», «Нота серця», «Кінцева нота»).
2. **`scrapers/pyramid_classifier.py`:**
   * Нормалізатор українських та англійських назв нот до 14 підгруп Колеса.
